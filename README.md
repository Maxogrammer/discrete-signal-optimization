# Оптимизация периода передачи дискретного сигнала между двумя системами

Проект посвящен задаче выбора оптимального интервала дискретной передачи данных между системами при ограничениях на точность сохранения информации и нагрузку на канал связи.

Работа выполнена на кафедре компьютерного моделирования физических процессов физического факультета БГУ (проект 1 курса от кафедры, 3 студента, оценка защиты участников проекта: 9, 9, 8).
Автор теоретической модели и статьи, а также лидер команды: Тубольцев М. Е.

Полный текст исследования: [paper/Оптимальный период передачи дискретного сигнала между двумя системами.pdf](./paper/Оптимальный период передачи дискретного сигнала между двумя системами.pdf) (19 страниц, скомпилировано в LaTeX).

## Суть проблемы и математическая модель

Рассматривается система-отправитель, которая находится в дискретных состояниях и меняет их во времени. При передаче данных с постоянным интервалом возникают отклонения:
$$t_i = m_i \tau + \Delta t_i, \quad m_i = \left[ \frac{t_i}{\tau} \right]$$

Для сохранения информации о длительности состояний минимизируется суммарная абсолютная погрешность:
$$\Phi(\tau) = \sum_{i=1}^n |\Delta t_i| = \sum_{i=1}^n \left| t_i - \left[ \frac{t_i}{\tau} \right] \tau \right| \to \min$$

### Почему не работает градиентный спуск
Анализ производных функционала ошибки показывает, что вторая производная тождественно равна нулю почти всюду на области определения (вне точек разрыва функции округления):
$$\Phi''_\tau(\tau) = 0$$
Поскольку все точки поверхности ведут себя как точки перегиба, стандартные градиентные методы оптимизации здесь неприменимы.

## Реализованные алгоритмы

1. ММСП (Метод минимизации суммы погрешностей):
   Численный одномерный поиск минимума функционала с переменным шагом на ограниченном интервале. В базовой версии интервал ограничен $\min(T)$, в модифицированной — средним арифметическим выборки.
2. ЦНОД (Центрированный наибольший общий делитель):
   Эвристический алгоритм, основанный на разложении интервалов на простые множители. Значение периода передачи вычисляется по аналогии с координатой центра масс системы материальных точек:
   $$\tau = \frac{\sum_{i=2}^N l_i \cdot p_i}{\sum_{j=2}^N l_j}$$
   где $p_i$ — простой множитель, а $l_i$ — число его вхождений в выборку.

## Эмпирическая верификация

Тестирование алгоритмов проведено на реальном датасете из 27 дней непрерывной телеметрии использования смартфона (207 циклов активности). Учитывались четыре режима: ожидание, видео, музыка, звонок.

Критерий качества — добротность, отражающая относительное отклонение к величине интервала:
$$\zeta = \frac{|\Delta t|}{\tau} \cdot 100\%$$

### Результаты расчетов (модуль run_benchmark.py)

| Режим деятельности | tau (ЦНОД) | tau (ММСП баз) | tau (ММСП мод) |
| :----------------- | :--------: | :------------: | :------------: |
| Ожидание           |  32.8 мин  |    1.2 мин     |    35.0 мин    |
| Видео              |  10.9 мин  |    4.8 мин     |    4.8 мин     |
| Музыка             |  12.6 мин  |    1.4 мин     |    1.4 мин     |
| Звонок             |  2.6 мин   |    1.0 мин     |    1.3 мин     |

Сводные погрешности:
- ЦНОД: дифференциальная ошибка = 11%, интегральная ошибка = 4%, средняя добротность = 25.7%.
- ММСП (базовый): дифференциальная ошибка = 1.5%, интегральная ошибка = 0.5%, средняя добротность = 18.6%.
- ММСП (модифицированный): дифференциальная ошибка = 5.1%, интегральная ошибка = 2.9%, средняя добротность = 24.3%.

Вывод: алгоритм ЦНОД позволяет увеличить интервал отправки данных в 3–10 раз по сравнению с ММСП при сохранении близкой добротности (около 24–27%), что существенно снижает частоту пробуждения передатчика и нагрузку на канал.

## Быстрый старт

Для запуска бенчмарка не требуются внешние библиотеки (используется только стандартная библиотека Python):

```bash
# Клонирование репозитория
git clone https://github.com/[твой_username]/discrete-signal-optimization.git
cd discrete-signal-optimization

# Запуск расчета и вывод таблицы результатов
python run_benchmark.py
```

### Запуск интерфейса визуализации (опционально)
В проекте есть приложение на Tkinter и Matplotlib для просмотра графиков разрядки:
```bash
pip install -r requirements.txt
python Application/visualization.py
```

## Структура репозитория

- run_benchmark.py: консольный скрипт для быстрого воспроизведения расчетов разделов 4 и 5 статьи.
- requirements.txt: зависимости для графического интерфейса (matplotlib).
- paper/: чистовой PDF статьи (19 страниц) и исходные файлы LaTeX в подпапке src/.
- Data/: сырые логи (Phone1.txt) и предобработанная телеметрия (Phone1.json).
- Encryption/: расчетные модули ЦНОД (ideal_interval.py), погрешностей (errors.py) и кодирования сигналов.
- Application/: код визуализации графиков разрядки (visualization.py).
